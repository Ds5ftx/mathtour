# 서울한양도성 낙산 구간 Math Tour

혜화문에서 흥인지문까지(약 2.1km) 한양도성 낙산 구간을 걸으며 수학을 탐구하는 모바일 웹앱입니다.
(사)전국수학문화연구회 2026년 11월 7일(토) ~ 8일(일) 연수용 자료입니다.

- 12개 지점별 해설, 수학으로 읽기, 직접 계산해 보는 도구, 현장 질문과 풀이
- 지점 표지: 태조 때 천자문 공사 구간 글자(來~歲)
- 다음 날 남산 구간(봉수대) 미리 보기

`index.html` 한 파일로 동작합니다(사진 포함). GitHub Pages를 켜면 휴대폰에서 바로 열 수 있습니다.
